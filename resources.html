Code

I try to make what I develop available and you can find much of it on my github profile. In particularly, check out:

  • Assets, Snapchat lenses, study data, analysis, and video for "Body-Based Augmented Reality Feedback During Conversations ": https://github.com/henningpohl/Body-Based-Visualization
  • Assets and Unity project sources used for "Poros: Configurable Proxies for Distant Interactions in VR": https://github.com/henningpohl/poros
  • Assets, evaluation data, and corresponding Unity project sources used for "Hafnia Hands: A Multi-Skin Hand Texture Resource for Virtual Reality Research": https://github.com/henningpohl/Hafnia-Hands
  • Source code for AR editor and runtime described in "Body LayARs: A Toolkit for Body-Based Augmented Reality": https://github.com/henningpohl/body-based-ar-tk
  • Schematics and firmware used for itch feedback prototype in "ElectricItch: Skin Irritation as a Feedback Modality": https://github.com/henningpohl/itch-feedback
  • Code to control a WeMo power switch over WiFi: https://github.com/henningpohl/WeMo
  • Very basic implementation of the socket.io protocol for UWP applications: https://github.com/henningpohl/socket.io-uwp

Datasets

I maintain the hcidata package for R, which contains the data from several HCI studies. Study data from these papers of mine is included:

  • Bergström, Joanna, Jarrod Knibbe, Henning Pohl, and Kasper Hornbæk. 2022. "Sense of Agency and User Experience: Is There a Link?” ACM Trans. Comput.-Hum. Interact. 29 (4)
  • Larsen, Joachim Normann, Tórur Højgaard Jacobsen, Sebastian Boring, Joanna Bergström, and Henning Pohl. 2019. "The Influence of Hand Size on Touch Accuracy." In Proceedings of the 21st International Conference on Human-Computer Interaction with Mobile Devices and Services. MobileHCI '19
  • Lilija, Klemen, Henning Pohl, Sebastian Boring, and Kasper Hornbæk. 2019. "Augmented Reality Views for Occluded Interaction." In Proceedings of the 2019 CHI Conference on Human Factors in Computing Systems, 1–12. CHI '19
  • Pohl, Henning, and Aske Mottelson. 2022. "Hafnia Hands: A Multi-Skin Hand Texture Resource for Virtual Reality Research." Frontiers in Virtual Reality 3
  • Pohl, Henning, and Roderick Murray-Smith. 2013. "Focused and Casual Interactions: Allowing Users to Vary Their Level of Engagement." In Proceedings of the SIGCHI Conference on Human Factors in Computing Systems, 2223–32. CHI '13
